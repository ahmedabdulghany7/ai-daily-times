# ✨ Particle Hero

Particles swarm into your brand name in 3D. Move the cursor to push them, click to blast.

**Live:** [Demo](https://ahmedabdulghany7.github.io/ai-daily-times/web/hero/) · [Particles only](https://ahmedabdulghany7.github.io/ai-daily-times/web/hero/?ui=0)

Make it yours: open [`index.html`](index.html), edit the `CONFIG` block at the top (brand, tagline, colors, buttons, links), save, refresh.

Designed and developed by Ahmed Abdulghany (@ai.dailytimes).
